# GAISS 2026 submission checklist

Target: IEEE Conference on Generative AI for Secure Systems (GAISS 2026),
Track 10 (Agentic and Autonomous Generative AI Systems in Secure Environments).
Submission via EasyChair: https://easychair.org/conferences?conf=gaiss2026

## Verified

- [x] Paper is 5 pages including references (GAISS limit: 6).
- [x] PDF page size is US Letter (612 x 792 points).
- [x] IEEE conference two-column class (IEEEtran) is used.
- [x] Double-blind: author names, affiliations, and emails removed from source.
- [x] PDF metadata author is "Anonymous"; no identifying producer metadata.
- [x] No identifying strings in the rendered PDF text.
- [x] No self-identifying phrasing ("our previous work") anywhere in the text.
- [x] No self-identifying project URLs in the manuscript.
- [x] All fonts embedded; no unembedded font resources.
- [x] Zero LaTeX errors, zero overfull boxes, zero undefined citations.
- [x] 19 references cited, 19 present; no orphans in either direction.
- [x] Every reference is a peer-reviewed venue record except ExploitGym, the
      single approved preprint exception.
- [x] All 9 DOI-bearing references render a resolvable identifier.
- [x] Author lists and titles verified against the venue PDF where obtainable,
      and against Crossref/OpenAlex/Semantic Scholar otherwise.
- [x] ASCII hyphens only; no Unicode dash characters in source.
- [x] 120 runs across 12 balanced cells; 461 events reconciled.
- [x] Every reported count and Wilson interval reproduced from `runs.csv`.
- [x] Zero model/parse-error runs and zero post hoc exclusions.
- [x] Safety scope: symbolic world, localhost model endpoint only, no real
      vulnerability, shell, credential, arbitrary filesystem, or public target.
- [x] Artifact package rebuilt from anonymized sources; contains no identity.
- [x] Ethics and AI-assistance statement present and non-identifying.

## Author confirmation required before upload

- [ ] Choose the EasyChair track (Track 10 recommended; Track 02 is the
      fallback if the framing is presented as adversarial rather than
      architectural).
- [ ] Confirm EasyChair portal metadata does not reveal author identity.
- [ ] Decide whether to keep the "Artifact, Ethics, and AI Assistance"
      section. GAISS instructs authors to omit acknowledgments from the review
      version; this section names no one, but a literal reading would drop it.
- [ ] Decide whether to attach the artifact ZIP. GAISS states no artifact
      policy, and supplementary material must also be anonymized.
- [ ] Confirm funding and conflict-of-interest status; neither was invented.
- [ ] Read the final PDF and accept responsibility for the claims.

## Open questions only the chairs can answer

The GAISS site does not state whether references count toward the six-page
limit, and does not link an IEEE template file. The submission conforms to
standard IEEEtran two-column and fits six pages including references, which
satisfies either reading. Contact: generalchair@gaiss.info
